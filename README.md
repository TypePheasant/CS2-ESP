## Usage

1. Unpack the archive to a folder.
2. Run the `CS2_ESP_Config.exe` to select your preferences.
3. Launch CS2 in borderless windowed mode.
4. Press `Home` to open the in‑game configuration panel.
5. Toggle modules and adjust colours.
6. Save your profile for quick loading.

## About the project

CS2-ESP is a full‑featured external overlay configuration collection for CS2. It demonstrates how to build a comprehensive visual assistance system using only UI customisation and external rendering – no game memory modification.
